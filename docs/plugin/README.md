# Sample Plugin

Save a display name and see a personal greeting with the current time.

## What you can do

- Save your display name on this device.
- Show a greeting using your saved name and the current time.
- Use the page in English or Chinese, following Seed's language.

## Get started

Once the plugin is loaded in Seed, open **Sample Plugin**. Enter a name under **Display name**, choose **Save**, then choose **Show greeting**. Leave the name empty to use “friend”.

The saved name remains after reopening the page. **Reload saved** reads the latest saved name and discards unsaved changes. If another page changed the name, copy any draft you need before reloading.

## Example

Save “Ada” and choose **Show greeting** to see “Hello, Ada!” followed by the current time. A greeting uses the saved name; changing the text without saving does not change the greeting.

## Permissions and scope

Requires MotusAI Seed 0.3.11 or newer. The plugin stores only the display name on this device, does not contact an external service, and requests no additional system permissions. Names can contain up to 80 characters.
