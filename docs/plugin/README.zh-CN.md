# 示例插件

保存显示名称，并查看带有当前时间的专属问候。

## 可以做什么

- 在当前设备保存显示名称。
- 根据已保存的名称和当前时间查看问候。
- 跟随 Seed 的语言使用中文或英文页面。

## 开始使用

插件在 Seed 中加载后，打开「示例插件」。在「显示名称」中输入名字，点击「保存」，再点击「查看问候」。名称留空时使用「朋友」作为称呼。

重新打开页面后仍能读取已保存的名称。「重新读取」会读取最新保存的名称，并放弃尚未保存的修改。如果名称已在其他页面修改，请先按需复制当前草稿，再重新读取。

## 使用示例

保存「小明」后点击「查看问候」，即可看到「你好，小明！」以及当前时间。问候使用已保存的名称；只修改输入框但没有保存，不会改变问候中的称呼。

## 权限与使用范围

需要 MotusAI Seed 0.3.11 或更新版本。插件只在当前设备保存显示名称，不连接外部服务，也不申请额外系统权限。名称最多包含 80 个字符。
